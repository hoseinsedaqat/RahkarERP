## پیش‌نیازِ همه‌ی مسیرها

ابتدا Node.js نسخه‌ی ۲۰ یا بالاتر را نصب کنید: [nodejs.org](https://nodejs.org)
(در ویندوز «همیشه گزینه‌ی Add to PATH را تیک بزنید»).

سپس کد را بگیرید:

```bash
git clone https://github.com/h03einsedaqat/erpv2.git
cd erpv2
npm install
```

## مسیر ۱: نسخه‌ی نمایشیِ اینترنتی (بدون نصب)

برای آشنایی و ارائه به مشتری، کافی است خروجیِ استاتیک را بسازید:

```bash
npm run build:demo
```

پوشه‌ی `dist` ساخته می‌شود (شامل `.nojekyll` و `404.html`). آن را روی Netlify یا هر هاستِ
استاتیکِ دیگری منتشر کنید؛ در Netlify کافی است Build command را `npm run build:demo`
و Publish directory را `dist` بگذارید.
در این نسخه هیچ سروری وجود ندارد و داده‌ها فقط در مرورگرِ بازدیدکننده می‌مانند.

نشانیِ نسخه‌ی نمایشیِ فعلی:
```
https://rahkar-erp.netlify.app
```

کاربرانِ نمایشی: `admin / admin123`، `hesabdari / 1234`، `foroosh / 1234`، `anbar / 1234`

## مسیر ۲: اجرا روی ویندوز

> راهنمای کامل، با رفع اشکال‌های رایج و روش‌های سرویس دائمی: [`راهنما-اجرا-ویندوز.md`](راهنما-اجرا-ویندوز.md)

پیش‌نیاز: Node.js نسخه‌ی 20.19+ یا 22.12+ (۲۳ و ۲۴ هم پشتیبانی می‌شوند).

۱) وابستگی‌ها را نصب کنید:

```bat
npm install
```

۲) فایلِ تنظیمات را بسازید (اختیاری؛ پیش‌فرض‌ها برای اجرای محلی کافی‌اند):

```bat
copy .env.example .env
```

در `.env` می‌توانید `PORT` (پیش‌فرض ۸۰۸۰) و `JWT_SECRET` را تنظیم کنید. اگر `JWT_SECRET` را خالی بگذارید،
سرور خودش یک کلیدِ پایدار در پوشه‌ی `.data` می‌سازد.
(برای ساختِ رشته‌ی تصادفی: `node -e "console.log(require('crypto').randomBytes(48).toString('hex'))"`)

۳) برنامه را بسازید و اجرا کنید — یکی از این دو:

```bat
npm start
```
یا دوبار کلیک روی `scripts\windows\راه‌اندازی-ویندوز.bat`

۴) در مرورگر بروید به: `http://localhost:8080` — ورود: `admin / admin123`

۵) سرویسِ ویندوز (اختیاری — برای اینکه همیشه اجرا باشد):
- برنامه‌ی [NSSM](https://nssm.cc/download) را دانلود کنید و در Command Prompt (Administrator):
  ```bat
  nssm install RahkarERP "C:\Program Files\nodejs\node.exe" "--import tsx server/index.ts"
  nssm set RahkarERP AppDirectory "C:\مسیر\پروژه"
  nssm set RahkarERP AppEnvironmentExtra PORT=8080 NODE_ENV=production
  nssm start RahkarERP
  ```
  (ساده‌تر: از Task Scheduler یک کار برای `راه‌اندازی-ویندوز.bat` در زمانِ بوت بسازید.)

۶) پشتیبان‌گیری: پوشه‌ی `.data` را هر شب با یک فایلِ `.bat` ساده کپی کنید، یا از
دکمه‌ی «دریافت نسخه‌ی پشتیبان» در بخشِ «سازمان» استفاده کنید.

## مسیر ۳: اجرا روی لینوکس (سرور)

```bash
# ۱) نصبِ پیش‌نیازها
sudo apt update && sudo apt install -y git nginx
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -   # نسخه‌ی 22 LTS (20.19+ هم کافی است)
sudo apt install -y nodejs

# ۲) گرفتنِ برنامه
git clone https://github.com/h03einsedaqat/erpv2.git
cd erpv2
npm install
cp .env.example .env

# ۳) تنظیمات
nano .env       # PORT=4000 و JWT_SECRET را پر کنید

# ۴) ساخت و اجرا
npm run build
npm start
```

برای اجرای دائم با systemd، فایل `/etc/systemd/system/rahkar.service` را بسازید:

```ini
[Unit]
Description=Rahkar ERP
After=network.target

[Service]
WorkingDirectory=/root/erpv2
ExecStart=/usr/bin/npm start
Restart=always
Environment=NODE_ENV=production
EnvironmentFile=/root/erpv2/.env

[Install]
WantedBy=multi-user.target
```

سپس:

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now rahkar
sudo systemctl status rahkar
```

و در انتها Nginx را برای SSL و反向 پروکسی تنظیم کنید (نمونه):

```nginx
server {
  listen 80;
  server_name your-domain.com;
  location / { proxy_pass http://127.0.0.1:4000; proxy_set_header Host $host; }
}
```

و با `sudo certbot --nginx` گواهیِ رایگان بگیرید.

## مسیر ۴: داکر

```bash
# ساختِ تصویر
docker build -t rahkar-erp .

# اجرا (با ذخیره‌ی داده‌ها روی دیسکِ میزبان)
docker run -d --name rahkar -p 4000:4000 \
  -e JWT_SECRET='یک-رشته-تصادفی-خیلی-بلند' \
  -v rahkar-data:/app/.data \
  rahkar-erp
```

یا با docker-compose:

```bash
docker compose up -d
```

## مسیر ۵: انتشارِ آنلاین با Supabase و ورود با گوگل

۱) پروژه‌ی Supabase بسازید و رشته‌ی اتصال را بگیرید
(جزئیات در «راهنما-پایگاه-داده.md»، بخشِ ۲).

۲) کلیدِ گوگل را بسازید (جزئیات در «راهنما-ورود-گوگل.md»، بخشِ اول).

۳) در `.env` بنویسید:

```env
DATABASE_URL=postgres://postgres.xxxx:PASSWORD@aws-0-...pooler.supabase.com:5432/postgres?sslmode=require
SUPABASE_URL=https://xxxx.supabase.co
SUPABASE_ANON_KEY=...
GOOGLE_CLIENT_ID=...apps.googleusercontent.com
GOOGLE_AUTO_SIGNUP=false
GOOGLE_DEFAULT_ROLE=viewer
GOOGLE_ALLOWED_DOMAINS=your-domain.com
CORS_ORIGIN=https://rahkar-erp.netlify.app
JWT_SECRET=...
```

۴) جداول را بسازید:

```bash
npm run migrate
```

۵) سرور را روی یک میزبان (Render / Railway / VPS) مستقر کنید و همان `.env` را به آن بدهید.

۶) frontend را با نشانیِ سرور بسازید و منتشر کنید:

```bash
VITE_API_BASE=https://api.your-domain.com npm run build:demo
```

۷) در تنظیماتِ گوگل، نشانیِ Pages را به **Authorized JavaScript origins** اضافه کنید.

## مسیر ۶: نصب به‌عنوان برنامه روی موبایل و دسکتاپ (PWA)

بدون نیاز به فروشگاهِ برنامه:

- **اندروید / کروم:** نشانیِ برنامه را در Chrome باز کنید → منوی سه‌نقطه →
  **«نصب برنامه» (Install app)**.
- **ویندوز / مک (Edge و Chrome):** در نوارِ آدرس آیکونِ نصب ظاهر می‌شود.
- **آیفون و آیپد (Safari):** دکمه‌ی **Share** → **Add to Home Screen**.

پس از نصب:
- برنامه تمام‌صفحه و بدونِ نوارِ مرورگر اجرا می‌شود،
- صفحات و فونت‌ها کش می‌شوند و **بدون اینترنت** باز می‌شوند،
- داده‌های مالی فقط زمانی که اینترنت دارید همگام می‌شوند (APIها هرگز کش نمی‌شوند).

## مسیر ۷: دریافت فایلِ نصبیِ ویندوز از GitHub Actions

چون ساختِ فایلِ `.exe` در محیطِ ابریِ محدود ممکن نیست، یک «کارخانه‌ی ساخت» در
گیت‌هاب آماده کرده‌ایم که فایلِ نصبی را برای شما می‌سازد:

1. در صفحه‌ی مخزنِ گیت‌هاب، تبِ **Actions** را باز کنید.
2. از سمتِ راست، workflowِ **«ساخت بسته‌ی ویندوز»** (build-windows) را انتخاب کنید.
3. دکمه‌ی **Run workflow** را بزنید و شاخه را انتخاب کنید.
4. پس از پایان (چند دقیقه)، روی اجرایِ موفق کلیک کنید و از پایینِ صفحه،
   بخشِ **Artifacts** فایلِ `RahkarERP-Windows-Package.zip` را دانلود کنید.
5. فایل را از حالتِ فشرده خارج کنید و `نصب-ویندوز.bat` را اجرا کنید.

محتوایِ بسته:
- پوشه‌ی `app`: برنامه‌ی کامل (backend + frontend)
- `نصب-ویندوز.bat`: اجرایِ خودکار (وابستگی‌ها را نصب و سرور را بالا می‌آورد)
- `راهنما-نصب.txt`: همان دستورهای این فایل به‌صورتِ متنِ ساده
