# سناریوی ویدئوی معرفی (۳:۳۰ دقیقه)

برای ضبط با هر ابزاری (OBS، Loom، یا ضبطِ مرورگر). متنِ زیر را می‌توانید بخوانید یا به زیرنویس تبدیل کنید.

| زمان | تصویر روی صفحه | متنِ گوینده |
| --- | --- | --- |
| ۰:۰۰–۰:۲۰ | صفحه‌ی آغازین و ورود | «راهکار؛ سامانه‌ی جامع مالی و عملیاتی برای کسب‌وکاری که حسابدار ندارد.» |
| ۰:۲۰–۰:۵۰ | داشبورد و نوارِ کناری | «همه‌چیز از یک جا: فروش، خرید، انبار، خزانه، حقوق و حسابداری.» |
| ۰:۵۰–۱:۲۰ | انتخاب‌گرِ شرکت + ساختِ شرکت | «اگر چند کسب‌وکار دارید، هر کدام داده‌ی کاملاً جدا و شماره‌گذاریِ خودش را دارد.» |
| ۱:۲۰–۱:۵۰ | راهنمای راه‌اندازی (۵ گام) | «پنج گام: قالبِ کسب‌وکار، سال مالی، سرفصل‌های حسابداری، کاربران، پایان.» |
| ۱:۵۰–۲:۲۰ | تبادل داده با اکسل | «اطلاعات قدیمی‌تان را از اکسل می‌آورید: قالب بگیرید، پر کنید، وارد کنید.» |
| ۲:۲۰–۲:۴۵ | ثبت سند + صورت‌های مالی | «هر سند با دو سطر ثبت می‌شود و ترازنامه و سود و زیان همان لحظه به‌روز می‌شوند.» |
| ۲:۴۵–۳:۰۵ | چک و چاپِ PDF | «چک و فاکتور را با قالبِ رسمی و مبلغ به حروف چاپ یا PDF بگیرید.» |
| ۳:۰۵–۳:۲۰ | پشتیبان‌گیری | «یک کلیک پشتیبان، یک کلیک بازگردانی؛ نسخه‌ی امن همیشه نگه داشته می‌شود.» |
| ۳:۲۰–۳:۳۰ | پایان | «راهکار؛ دفترِ مالیِ شما، بدون هزینه‌ی حسابدار.» |

## نکاتِ ضبط
- وضوح ۱۰۸۰p، صدای واضح، موس با حرکتِ آرام.
- از داده‌ی نمونه استفاده کنید، نه اطلاعات واقعیِ مشتریان.
- در پایان آدرسِ پروژه و راهنمای کاربر را نشان دهید.
